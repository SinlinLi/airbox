  1. Receiver generates keys → sends public key to sender (safe to expose)
  2. Sender pastes public key → types message → sends ciphertext back
  3. Receiver pastes ciphertext → decrypts with private key

Everything runs locally. No data leaves your browser. Max message: 190 bytes. Close the tab when done — keys only exist in memory.
